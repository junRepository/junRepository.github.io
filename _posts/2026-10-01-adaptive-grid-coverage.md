## 1. 문제: 이동한 공간과 관측한 공간은 다르다

커버리지 경로계획은 주어진 영역을 빠짐없이 방문하거나 관측하도록 경로를 만드는 문제입니다. 창고 모니터링에서는 로봇의 중심점이 지나간 궤적뿐 아니라, **그 위치에서 카메라가 실제로 볼 수 있는 영역**이 중요합니다.

실내 창고에는 넓은 자유공간, 선반 사이의 좁은 통로, 장애물 경계가 함께 존재합니다. 같은 크기의 그리드를 전체 지도에 적용하면 다음과 같은 문제가 생깁니다.

- 작은 셀을 사용하면 넓은 공간에도 많은 셀과 경유점이 생겨 경로가 복잡해집니다.
- 큰 셀을 사용하면 좁은 통로나 장애물 주변의 구조를 충분히 표현하기 어렵습니다.
- 셀 개수만 비슷하게 나누어도 셀 크기와 이동 비용이 다르면 로봇별 작업 부담은 달라집니다.

따라서 저는 **공간을 표현하는 방식과 여러 로봇에 일을 나누는 방식을 함께 설계**하는 방향으로 접근했습니다.

## 2. 전체 접근 방법

![센서 풋프린트 계산, 지도 특징 추출, 적응형 그리드 생성, 영역 할당과 경로 생성으로 이어지는 연구 구조]({{ '/images/research/adaptive-grid-pipeline.png' | relative_url }})
*석사논문 그림 3-1에 해당하는 전체 구조. 발표자료의 원본 그림을 사용했습니다.*

처리 순서는 다음과 같습니다.

1. Gazebo 창고 환경의 장애물 위치·크기·충돌박스 정보를 2D 레이아웃으로 변환합니다.
2. 카메라 화각과 비행 고도로 센서 풋프린트를 계산합니다.
3. 자유공간, 장애물 경계, 장애물 거리 정보를 전처리하고 CNN 특징을 추출합니다.
4. 인접 셀 병합과 잔여 셀 흡수로 적응형 그리드를 구성합니다.
5. 셀 그래프에서 로봇별 연결 영역을 할당하고 지역 균형화를 수행합니다.
6. 각 영역에서 STC 계열 커버리지 경로를 생성하고 비용을 평가합니다.

## 3. 카메라 관측 범위를 그리드의 기준으로 사용하기

센서 풋프린트는 한 위치에서 센서가 관측할 수 있는 영역입니다. 논문에서는 카메라의 수평·수직 시야각과 비행 고도로 풋프린트의 폭과 높이를 계산했습니다.

```text
footprint_width  = 2 × h × tan(HFOV / 2)
footprint_height = 2 × h × tan(VFOV / 2)
```

실험에 사용한 값은 비행 고도 **5.5 m**, 수평 시야각 **82.6°**, 수직 시야각 **66°**입니다. 이 관측 범위는 셀 크기와 커버 경로를 구성하는 기준이 됩니다. 실제 관측에서는 자세 변화와 가림이 영향을 줄 수 있으며, 본 연구에서는 논문에 정의한 2D 관측 모델을 기준으로 다룹니다.

중요한 점은 큰 셀을 생성했다고 해서 그 셀 전체를 한 번에 촬영한다고 가정하지 않는다는 것입니다. 병합된 셀 내부에도 관측 범위를 고려한 커버 경로가 필요하며, 그 비용을 영역 할당에 반영합니다.

## 4. 기하학적 정보와 CNN 특징으로 공간 표현하기

### 4.1 지도는 세 가지 정보로 구성한다

입력 지도에서 자유공간 마스크, 장애물 경계 정보, 장애물 거리 정보를 만듭니다. 각각 이동 가능한 영역, 장애물 주변의 구조, 장애물과의 여유 거리를 표현합니다.

여기에 ImageNet 사전학습 **ResNet18**의 특징을 활용합니다. 사전학습 가중치는 고정하고 파인튜닝하지 않았으며, 셀에 대응하는 특징 영역을 평균 풀링해 셀 임베딩을 얻었습니다.

이때 CNN은 경로를 직접 출력하는 모델이 아닙니다. **인접 셀의 공간 구조가 얼마나 유사한지 비교하는 보조 특징 추출기**로 사용했습니다. 실제 병합은 자유공간 비율, 장애물 경계, 거리와 같은 기하학적 조건을 함께 검사해 결정합니다.

### 4.2 병합과 흡수는 역할이 다르다

**병합(Merge)**은 조건을 만족하는 인접한 2×2 셀을 상위 크기의 셀로 묶는 과정입니다. 넓고 단순한 자유공간의 불필요한 세분화를 줄이는 역할을 합니다.

**흡수(Absorption)**는 병합 후 남은 작은 셀을 주변 셀에 통합하는 과정입니다. 자유공간 조건, 안전 여유, 형태 조건과 임베딩 유사도를 만족할 때만 적용합니다. 좁은 통로나 장애물 주변의 세부 표현을 유지하면서 작은 잔여 셀을 정리하는 데 목적이 있습니다.

최종 결과는 셀을 노드로, 이동 가능한 인접 관계를 간선으로 갖는 그래프입니다.

## 5. 면적보다 경로 비용을 기준으로 작업 나누기

각 로봇의 시작 셀을 기준점으로 두고 인접한 셀을 배정합니다. 셀의 커버 비용, 시작 위치에서 접근하는 비용, 로봇 간 부담을 함께 고려하며, 각 로봇의 영역은 하나의 연결된 영역으로 유지합니다.

초기 할당 이후에는 작업 부담이 큰 로봇의 경계 셀을 이웃 로봇으로 옮기는 **지역 균형화(Local Balancing)**를 수행합니다. 셀을 옮긴 뒤 두 로봇의 영역이 모두 연결되어 있고, 전체 최대 경로 비용이 감소하는 경우에만 갱신합니다.

```text
로봇별 경로 비용: C₁, C₂, …, Cₙ
Makespan = max(C₁, C₂, …, Cₙ)
Total path = C₁ + C₂ + … + Cₙ
```

논문에서 Makespan은 **가장 긴 로봇 경로의 비용**입니다. 여러 로봇이 동시에 작업할 때 병목을 나타내는 지표로 사용했으며, 실제 초 단위의 완료시간을 직접 측정한 값은 아닙니다.

영역 할당이 끝나면 STC(Spanning Tree Coverage) 계열의 Hybrid STC 방식으로 경로를 생성합니다. 서로 다른 크기의 셀을 연결하고 순회점을 구성해, 영역 분할 결과를 실제 평가 가능한 경로로 변환합니다.

## 6. 실험은 무엇을 비교했는가

주요 내부 비교 실험은 **4개 지도 × 4개 방법 × 로봇 수 5조건 × seed 5조건 = 400회**로 구성했습니다.

| 구분 | 실험 설정 |
| :--- | :--- |
| 지도 | Jetty, Warehouse, AWS Warehouse, Tugbot Depot |
| 로봇 수 | 2–6대 |
| 반복 조건 | seed 0–4 |
| 내부 비교 | Proposed, 균일 그리드, Voronoi balanced, MFC balanced |
| 추가 비교 | 같은 지도·로봇 수·시작 조건·평가 지표에 맞춘 LS-MCPP, TMSTC* |
| 지표 | 최대 경로 비용, 전체 경로 비용, 로봇별 경로 부담 표준편차, 회전 수 |

Voronoi balanced와 MFC balanced는 제안 방법과 **같은 적응형 그리드에서 영역 할당 방식**을 비교하는 기준입니다. 별도의 그리드 요소 비교에서는 Proposed, Quadtree, Geometry-only를 비교했습니다. 위 400회는 주요 내부 비교 실험의 횟수이며, 모든 추가 실험을 합산한 횟수로 사용하지 않았습니다.

### 6.1 기존 경로계획 방법과의 비교

다음은 석사논문 표 4-3의 전체 평균 결과입니다. 비용 값은 원문의 평가 척도를 그대로 옮겼으며, m나 s 단위로 환산하지 않았습니다. 경로 부담 표준편차의 `±` 표기도 원문을 따릅니다.

| 방법 | Makespan ↓ | Total path ↓ | Workload std ↓ | Turn count ↓ |
| :--- | ---: | ---: | ---: | ---: |
| **Proposed** | **1370.73** | **4584.89** | 53.95 ± 72.17 | 779.88 |
| LS-MCPP | 2123.68 | 7258.00 | 56.02 ± 48.56 | **605.75** |
| TMSTC* | 3921.86 | 13428.42 | **40.97 ± 22.04** | 651.58 |

평균값을 기준으로 계산하면 다음과 같습니다.

- **LS-MCPP 대비**: Makespan **35.45% 감소**, 전체 경로 비용 **36.83% 감소**.
- **TMSTC* 대비**: Makespan **65.05% 감소**, 전체 경로 비용 **65.86% 감소**.

감소율은 `(비교 방법의 값 − 제안 방법의 값) / 비교 방법의 값 × 100`으로 계산했습니다.

제안 방법은 두 기준 방법보다 경로 비용이 낮았지만, **회전 수는 더 많았습니다.** 경로 부담 표준편차도 TMSTC*가 더 낮았습니다. 따라서 결과는 모든 지표에서의 우위가 아니라, 본 실험 조건에서 **최대 경로 비용과 총 이동 비용을 줄인 성과**로 해석합니다.

### 6.2 공간 표현 자체의 효과

논문 표 4-1의 그리드 요소 비교에서는 제안 방법이 **288개 셀·420개 간선**, Quadtree가 530개 셀·883개 간선, Geometry-only가 671개 셀·1147개 간선을 생성했습니다.

이 요소 비교 조건에서 평균 Makespan은 각각 1842.31, 2396.98, 2828.22였습니다. 동일한 후속 영역 할당·경로 생성 절차에서 공간 표현의 차이가 경로 비용으로 이어지는지를 확인한 결과입니다. 앞 절의 전체 평균 표와는 별도의 비교이므로 수치를 섞어서 해석하지 않습니다.

## 7. 연구에서 다룬 기여와 남은 과제

이 석사 연구에서 저는 **센서 관측 범위에 근거한 공간 표현 → 적응형 셀 그래프 → 로봇별 작업 배분 → 경로 생성과 평가**를 하나의 절차로 구성했습니다. 특히 CNN 특징을 활용하는 부분과 기하학적 제약을 검사하는 부분을 구분하고, 실험에서는 공간 표현과 영역 할당의 영향을 나누어 분석했습니다.

한편 실험은 2D 지도 기반 경로계획에 한정됩니다. 실제 로봇 동역학, 센서 노이즈, 실시간 장애물 회피와 통신 지연은 직접적인 검증 범위에 포함하지 않았습니다. 경로의 연결성을 유지하는 것만으로 여러 로봇의 시간상 충돌 회피까지 보장되는 것도 아닙니다.

후속 과제는 증가한 회전 수를 실제 운용 비용과 함께 평가하고, 계획된 관측 범위와 실제 영상의 관측 범위가 얼마나 일치하는지 확인하는 것입니다. 경로 길이만으로 판단하지 않고, 비행·회전·촬영이 함께 만드는 비용을 다루는 방향으로 확장할 수 있습니다.
